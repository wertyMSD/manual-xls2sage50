# XLS2Sage50

Importador de datos Excel/CSV hacia **SAGE 50** para Windows: vía API
directa o generación de ficheros CSV para importación manual.

## Novedades

### 0.1.0 — Primera versión pública (2026-08-17)

Importación API (Artículos, Clientes, Proveedores), modo CSV, plantillas de
mapeo reutilizables, verificación de campos obligatorios, CLI de
automatización, interfaz de escritorio y web, y auto-actualización con
manifest firmado.

Ver detalles en el [manual](https://alfonsoautomatiza.github.io/xls2sage50/novedades/).

## Descarga

Descarga gratuita desde
[GitHub Releases](https://github.com/alfonsoautomatiza/xls2sage50/releases).

## Requisitos

- Windows 10/11 (64 bits)
- SAGE 50 (el modo API requiere licencia; el modo CSV no)
