# Novedades

## 0.1.0 — Primera versión pública (2026-08-17)

- **Lanzamiento inicial estable** de XLS2Sage50 para Windows (win-x64).
- **Importación por API**: Artículos, Clientes y Proveedores con conexión
  directa a SAGE 50 (requiere licencia API).
- **Modo CSV**: generación de ficheros CSV para importación manual en
  SAGE 50, disponible sin licencia API.
- **Plantillas de mapeo** reutilizables y auto-mapeo de columnas Excel.
- **Verificación previa** de campos obligatorios antes de cada importación.
- **Línea de comandos** para automatización: `run`, `validate`, `list`,
  `api-check`.
- **Interfaz de escritorio y web** desde el mismo ejecutable.
- **Actualizaciones automáticas** con manifest firmado.

Descarga: [GitHub Releases](https://github.com/alfonsoautomatiza/xls2sage50/releases)
