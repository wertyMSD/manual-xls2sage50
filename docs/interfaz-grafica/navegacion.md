# Barra de Navegación

La barra lateral de navegación permite cambiar entre las secciones de xls2sage50. Cada sección se identifica con su icono correspondiente.

## Secciones de la Aplicación

| Icono | Sección | Contenido |
|-------|---------|-----------|
| :material-home: | Inicio | Vista principal y acceso rápido |
| :material-table_large: | Proceso API | Importación directa por API |
| :material-file_csv: | Proceso CSV | Generación de archivos CSV |
| :material.bookmark: | Plantillas | Gestión de plantillas guardadas |
| :material.settings: | Configuración | Ajustes de la aplicación |

## Cambiar de Sección

1. Haga clic en el icono de la sección en la barra lateral
2. O use el atajo de teclado asignado a cada sección

## Atajos de Teclado

| Atajo | Acción |
|-------|--------|
| `Ctrl + 1` | Ir a Inicio |
| `Ctrl + 2` | Ir a Proceso API |
| `Ctrl + 3` | Ir a Proceso CSV |
| `Ctrl + 4` | Ir a Plantillas |
| `Ctrl + 5` | Ir a Configuración |
| `Ctrl + N` | Nuevo proceso |
| `Ctrl + O` | Abrir archivo |
| `Ctrl + S` | Guardar |
| `F5` | Actualizar |
| `Esc` | Cancelar la operación actual |

## Navegación desde los Menús

El menú **Archivo** da acceso a nuevo proceso, abrir plantilla y guardar plantilla. El menú **Ver** permite cambiar entre modos y mostrar u ocultar paneles. El menú **Ayuda** incluye la documentación, el diagnóstico y la información de la aplicación.

## Abrir un Archivo

Use el botón "Seleccionar Archivo" o arrastre el archivo Excel desde el explorador de archivos y suéltelo en el área de trabajo.
