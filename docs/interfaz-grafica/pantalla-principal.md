# Pantalla Principal

La pantalla principal de xls2sage50 se organiza en cuatro áreas: la barra superior, el área de trabajo, la barra lateral de navegación y la barra de estado.

## Barra Superior

| Menú | Contenido |
|------|-----------|
| **Archivo** | Nuevo proceso, abrir plantilla, guardar plantilla, salir |
| **Editar** | Configuración y preferencias |
| **Ver** | Cambiar entre modos, mostrar u ocultar paneles |
| **Ayuda** | Documentación, diagnosticar, acerca de |

## Área de Trabajo

Es el área central de la ventana. Su contenido cambia según la sección seleccionada en la barra lateral:

- **Inicio:** pantalla de bienvenida y acceso rápido
- **Proceso API:** herramientas de importación por API
- **Proceso CSV:** generación de archivos CSV y SQL
- **Plantillas:** gestión de plantillas guardadas
- **Configuración:** ajustes de la aplicación

## Barra de Estado

| Campo | Descripción |
|-------|-------------|
| **Estado** | Listo, Procesando o Error |
| **Conexión** | Estado de la conexión con SAGE 50 |
| **Progreso** | Barra de progreso de las operaciones |

## Pantalla de Bienvenida

En el primer arranque se muestra una pantalla de bienvenida con acceso a iniciar un nuevo proceso, cargar una plantilla, ver la documentación o configurar la aplicación. La casilla "No mostrar de nuevo" lleva directamente a la pantalla principal en los siguientes inicios.
