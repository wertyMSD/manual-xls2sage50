## Especificaciones Técnicas

### Formato
- **Formato:** PNG (para gráficos) o JPG (para capturas de pantalla)
- **Compresión:** Balance calidad/tamaño óptimo
- **Color:** sRGB

### Dimensiones
- **Ancho mínimo:** 400px
- **Ancho máximo:** 1200px
- **Alto:** Ajustar al contenido
- **Capturas completas:** Usar 1200x800px como estándar

### Texto Alternativo (Alt)
Cada imagen debe tener un atributo alt descriptivo que incluya:
- El contexto de la imagen
- Los elementos principales visibles
- El propósito de la imagen

### Convenciones de Nomenclatura

```
[tipo]-[accion]-[detalle].png
```

Ejemplos:
- `instalacion-pantalla-bienvenida.png`
- `importacion-basica-boton-importar.png`
- `configuracion-api-parametros.png`

## Herramientas Recomendadas

### Windows
- **Snipping Tool:** Para capturas básicas
- **ScreenToGif:** Para capturar secuencias
- **ShareX:** Para capturas avanzadas con anotaciones

### Anotación
- **Paint.NET:** Edición básica
- **GIMP:** Edición avanzada
- **Microsoft Paint:** Rectángulos y flechas simples

## Lista de Verificación Antes de Incluir

- [ ] La imagen es clara y nítida
- [ ] El tamaño es apropiado para la web
- [ ] No contiene información sensible (contraseñas, datos personales)
- [ ] El nombre de archivo sigue las convenciones
- [ ] Tiene texto alternativo descriptivo
- [ ] Está en el formato correcto
- [ ] El contraste es adecuado

## Notas para el Fotógrafo/Diseñador

1. **Consistencia:** Use el mismo tema (claro/oscuro) en todas las capturas
2. **Datos de prueba:** Use datos realistas pero ficticios
3. **Resolución:** Capture en resolución nativa del monitor
4. **Ventanas:** Capture solo la ventana relevante, no toda la pantalla
5. **Cursor:** Incluya el cursor cuando sea relevante para mostrar interacción
