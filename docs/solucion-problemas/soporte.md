## Información Necesaria

Cuando contacte con soporte, tenga preparada:

### Información del Sistema

| Información | Cómo Obtenerla |
|-------------|----------------|
| **Versión de xls2sage50** | Ayuda > Acerca de |
| **Versión de SAGE 50** | Ayuda > Acerca de en SAGE 50 |
| **Sistema operativo** | Panel de sistema > Acerca de |
| **Versión de Python** | `python --version` |

### Descripción del Problema

Proporcione una descripción detallada:

1. **Qué estaba haciendo** cuando ocurrió el problema
2. **Mensaje de error** exacto (si lo hay)
3. **Pasos para reproducir** el problema
4. **Qué ya ha intentado** para solucionarlo

### Archivos Adjuntos

Adjunte siempre que sea posible:

- [ ] Captura de pantalla del error
- [ ] Archivo de log (`xls2sage50.log`)
- [ ] Informe de diagnóstico
- [ ] Archivo Excel de ejemplo (sin datos confidenciales)
